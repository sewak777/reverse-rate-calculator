## Tweet 2

The Reverse Rate Calculator:
- Pick your skill, region, experience
- Get the actual hourly low / median / high
- Every number sourced from a named, dated public report

No accounts. No paywall. No "enter your email first."

thegaplist.com

## Tweet 3

The trust layer matters more than the feature set.

Every rate cell shows:
→ The exact sources (YunoJuno, Ruul.io, SoloPricing, etc.)
→ When the data was published
→ When we last verified it

If it's older than 6 months, a stale-data warning auto-renders. No hiding.

## Tweet 4

Two rules we won't break:

1. No LLM-generated rates. Models format and explain — the dollar values come from human-curated extraction.

2. No undated sources. If we can't tell you when the data was collected, we don't show the number.

A rate without a date is an opinion.

## Tweet 5

The stack is boring on purpose:

- Next.js 15, static JSON, Tailwind v4
- No database, no backend, no auth
- Quarterly manual data refresh

The whole product is one page reading a JSON file. Every minute saved on tooling is a minute spent on the data.

## Tweet 7

The project rates aren't made up either.

Each skill has a documented hour multiplier (a website is 40–80 hours, a logo is 4–12). Multiply by the hourly range → project rate.

The multipliers come from the same source set as the hourly data.
